# 严格 Top-K 的数值与权限核对

严格结果以入库和查询时实际存储的 float32 坐标为准，按真实余弦从高到低排列，余弦相等时按记录 ID 从小到大排列。对于完全相同的向量、同一组分量的不同排列、正负方向和第 K 名附近的近邻，这条规则相同。

生产代码先用 FP64 计算单位球上的弦长平方。两个分数足够接近、舍入可能改变排序时，会保留截断线两侧的候选，把相关 float32 坐标表示为二进制有理数。对同一个查询，比较有符号内积以及内积平方与对方范数平方的乘积，即可准确判定两条向量的先后。实际不等的分数仍能分出先后。独立基准全库穷举，近并列通过 Python 标准库 `Fraction` 复核。GloVe 前 20,000 行、测试集前 1,024 个查询，修正前后有序 Top-10 的全部 10,240 个位置相同。[运行时排序](../hpis/exact_order.py) · [独立参考](../bench/run.py)

| 可复核情形 | 观察结果 |
|---|---|
| 把 `[1, 0.5, −0.25, 0.125]` 的 24 种排列与全 1 查询比较 | 真实余弦相同，取 ID 最小的前 K 项 |
| 将 `[1, 2⁻³⁰]` 和 `[1, 2⁻³¹]` 与 `[1, 0]` 比较 | 后者排第一，保持能被普通 FP64 点积舍入掩盖的真实次序 |
| 归一化 `[1.6e−162, 1.6e−162]` | 与 `[1,1]` 的归一化结果一致，避免下溢的非零范数破坏单位球约束 |
| 距离保持表示接近与查询反向，且获胜项位于证书边缘 | 在 β=0.25 和 β=2 下，先扩大中心余弦的数值区间再计算角度上界，保留真实第一名 |
| 57 条数据，5 种维度、3 种 β、3 种 K、17 个查询 | Python 回退与原生内核共 1,530 次查询，全部有序 ID 与独立穷举一致 |

在项目根目录可重跑数值回归和两跳 TLS 集成测试。以下命令用本机 OpenSSL 编译原生内核。同一套测试也显式运行 Python 回退。

## 合设索引的权限和状态

HPIC 在已签名的匿名票据、持钥证明、请求时效和针对该索引的 owner 委托通过后进行精排。HPIS 在取正文前核对封装请求中的 AID、owner、索引标识和 K，校验结果 ID 的租户范围。HPIS 在同一个 SQLite 读事务中校验排名所用版本和读取正文。通过 SDK 的更新、删除与索引版本在同一写事务生效。若版本变化，重建密态副本、重试查询。持续写入时可能需要稍后重试。[权限和读写路径](../integration/mapped_index/protocol.py) · [隔离和更新测试](../integration/mapped_index/tests.py)

合设部署下，HPIC 跨请求保留该租户的 RAP、完整的原向量密文和公共证书辅助数组，以及用于匹配委托的稳定索引标识。每次授权的 HPIC 能接触查询、无噪旋转方向和向量密钥，能够打开完整副本内的原向量。部署时需将共享目录的写权限限于 HPIS，HPIC 仅有读权限。本次同机实验验证了程序的角色分工，独立操作系统角色或硬件隔离仍需在相应部署中验证。其受信边界、跨查询可链接性和存储成本均与只交付候选密文的部署有区别。业务实现不持久化精确向量、查询密钥或查询结果。版本检查保护已成功返回的结果一致性，旧副本在后续查询时替换。本次未验证同步物理擦除或抵抗恶意存储端遗漏。

## 热查询与索引准备

每组实验使用 2,048 组三路同题调用，三臂共享相同的验票策略，全部有序 Top-10 与参考一致。下表以两种明文对照中平均耗时较低者为分母。每次 bootstrap 也重新比较两个明文均值，按轮分层、配对的循环块长度为 16，复抽 2,000 次。

| 平台 | 热查询平均开销 | 95% 区间 | 密态副本 | 首个密态查询（含建副本） |
|---|---:|---:|---:|---:|
| Linux x86-64，前 512 个查询 | +7.33% | +6.94% 至 +7.96% | 16,720,256 B | 62.44 ms |
| Linux x86-64，后 512 个留出查询 | +11.89% | +11.23% 至 +12.73% | 16,720,256 B | 63.68 ms |
| Linux ARM64，前 512 个查询 | +7.80% | +6.57% 至 +9.06% | 16,720,256 B | 32.22 ms |

x86 留出集上，密态均值为 1.825 ms。同拓扑明文为 1.695 ms，开销 +7.69%。最快的原生明文为 1.631 ms，开销超过 10%。两类分母的结论应分别保留。

这些数字对应 20,000 条、100 维、β=0.25、Top-10、同机预置密态索引和获授权 HPIC。跨机器传输密态副本、冷启动和原有远程候选精排都有各自的成本。[x86 逐请求样本](../results/mapped_exact_x86/shared_auth/samples.jsonl.gz) · [x86 独立留出逐请求样本](../results/mapped_exact_x86/shared_auth_holdout/samples.jsonl.gz) · [ARM64 逐请求样本](../results/mapped_exact_archive/arm64_shared_auth/samples.jsonl.gz)
